articles/

## 备份说明

- **正文完整性**：`ARTICLE.md` 由 `raw/` 中的存档 HTML 逐节点转换生成，已逐段落比对源文本，正文文字无缺失；标题层级依据原帖字号还原。
- **格式保留**：原文的折叠区块（`<details>`）、代码块、列表、表格与链接均按原样保留。
- **图片**：原帖内嵌图片来自 MCBBS 图床，随站点关停已失效；存档站现存的两张表情图已下载至 `assets/` 并以相对路径引用，原图地址同时记录在 `metadata.json` 与转换脚本注释中。
- **未收录内容**：原文中「回复可见」的隐藏附件（自动重启脚本）存档站未保存，正文对应位置已加注说明。
